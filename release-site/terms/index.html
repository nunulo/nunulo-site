服务条款

使用 Nunulo 即表示你同意本条款和隐私政策。Nunulo 当前是个人运营的免费早期服务，目标是提供可实际使用的照片社区与地图相册，而不是承诺永久、无中断或无限容量。

1. 账号与资格

  • 用户应提供真实可用的登录信息并妥善保护账号，不得共享密码、令牌或绕过账号限制。
  • 公开注册需要接受当前条款和隐私政策；邀请码是可选加入方式，不代表特殊权利。
  • 未达到所在地区独立同意年龄的用户需获得监护人同意；中国境内未满十四周岁的用户不应自行注册。

2. 用户内容与授权

用户保留其上传内容的权利，并确认自己有权上传和分享这些内容。为了存储、压缩、生成缩略图、展示、备份、导出和按用户选择传播内容，用户授予 Nunulo 一项非独占、仅为提供和维护服务所必要的许可。删除内容或关闭匿名展示后，该许可在服务处理和备份保留所需范围内终止。

3. 可见范围

仅自己、关注者、所有成员和互联网匿名展示具有不同范围。用户负责在发布前选择合适范围。互联网匿名展示必须逐条主动开启，只提供受限缩略内容；即使如此，也不应发布敏感人物、未获同意的人像、家庭住址、学校、工作地点或其他可能造成伤害的信息。

4. 禁止行为

  • 上传违法、侵权、骚扰、欺诈、仇恨、露骨、危险或未经授权披露隐私的内容。
  • 冒用他人、批量注册、刷互动、绕过配额或限流、抓取非公开数据、攻击服务、传播恶意软件。
  • 利用地图和位置信息跟踪、骚扰、威胁他人，或公开受保护地点。
  • 干扰举报、审核、备份、安全调查或其他用户正常使用。

5. 内容治理

Nunulo 可以根据举报、法律要求和系统安全需要隐藏、限制或删除内容，停用账号，限制注册或调整配额。紧急风险或明显滥用可以先处理后通知；其他情况会尽量提供可理解的状态。管理员操作会保留必要审计记录。

6. 服务、容量与变更

服务可能因维护、故障、攻击、第三方服务变化或成本控制暂时不可用。公开注册账号使用有限初始配额，邀请账号和管理员调整的账号可能不同。Nunulo 可以在保护已有数据和提供合理迁移或导出机会的前提下调整功能、容量、接口和服务范围。

7. 数据导出、删除与备份

用户应保留重要照片的原始副本。Nunulo 提供个人数据导出，但不替代用户自己的长期备份。删除记录后会停止正常展示并清理对象；账号删除需通过私密入口验证身份。删除残留、日志和备份副本最长可能保留一年，详见隐私政策。

8. 免责声明与责任边界

在法律允许范围内，服务按现状提供，不保证持续可用、完全无误、满足特定用途或第三方地图和存储永不变化。Nunulo 不对用户自行公开敏感信息、设备或账号失控、第三方服务故障以及超出合理控制范围的间接损失承担责任；本条不排除法律不能排除的责任。

9. 条款更新与终止

条款发生实质变化时会更新版本日期，并可能要求用户重新确认。用户可以停止使用、删除内容、导出数据并申请删除账号。违反条款或威胁服务安全时，Nunulo 可以限制或终止使用。

10. 联系

一般反馈使用 GitHub Issues。账号删除、隐私或安全事项使用 GitHub 私密报告入口，请勿在公开页面提交密码、令牌、证件或其他敏感材料。
