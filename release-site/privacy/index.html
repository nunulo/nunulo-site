隐私政策

本政策说明 Nunulo 在提供照片记录、地图、社区互动、数据导出和匿名展示时如何处理信息。Nunulo 当前由个人开发者运营，不出售用户个人信息。

1. 收集的信息

  • 账号信息：用户名、可选邮箱、显示名、密码的安全哈希、登录设备类型和会话信息。
  • 用户内容：上传照片、派生缩略图、地点名称、坐标、拍摄时间、备注、标签、合集和可见范围。
  • 社区信息：关注、屏蔽、点赞、评论、通知、举报和管理处理记录。
  • 运行与安全信息：请求时间、请求标识、IP 或代理提供的客户端地址、错误和审计记录；日志不会主动记录密码、令牌、照片内容或请求体。

2. 使用目的

  • 创建和维护账号，提供登录、照片、地图、动态、互动、导出和管理功能。
  • 执行可见范围、位置降精度、存储配额、反滥用、内容治理、故障排查、备份和恢复。
  • 改进稳定性和安全性，调查违规、攻击、数据损坏或服务异常。

3. 匿名展示

“所有成员可见”和“互联网匿名展示”是两个独立选择。既有记录默认不会进入互联网窗口。只有用户逐条开启匿名展示的成员公开记录，才会向未登录访问者提供缩略图、公开文字、互动数量和降低到区域级的坐标。匿名接口不提供原图、对象存储地址、邮箱、用户名或完整个人资料。撤回后服务端立即停止提供该记录，但浏览器或边缘缓存可能在已声明的短缓存周期内继续存在。

4. 共享与处理方

服务运行依赖托管服务器、PostgreSQL/PostGIS、Cloudflare R2、Cloudflare 网络服务、高德地图和 GitHub Release。相关服务可能按各自政策处理必要的网络、存储、地图或分发数据。除提供服务、遵守法律、保护用户和系统安全外，Nunulo 不向第三方出售个人信息。

5. 位置与照片

Android 和浏览器仅在系统授权后请求定位或照片访问。记录保存用户确认的坐标；向其他成员展示时会按权限降低精度，互联网匿名展示进一步降低到区域级。请不要公开家庭、学校、工作场所或其他敏感位置；必要时使用更低可见范围或关闭匿名展示。

6. 保存期限

活跃账号中的内容在用户保留账号和内容期间持续保存，不会仅因上传满一年而自动删除。用户删除内容或提出账号删除请求后，在线数据会在合理时间内移除；为安全、审计、纠纷处理和恢复而保留的日志、删除残留及备份副本最长保留一年，法律另有要求或技术上已完成不可逆匿名化的情况除外。

7. 用户权利

用户可以在应用中查看、编辑、删除记录，调整可见范围和匿名展示，下载个人数据导出。账号停用、更正无法自行修改的信息、删除账号或其他隐私请求，可通过私密联系入口提交；需要先验证账号控制权。请勿在公开 Issue 中附密码、令牌、身份证件、原图或精确住址。

8. 安全与备份

Nunulo 使用私有对象存储、访问控制、派生媒体、配额、限流、审计和分层备份保护数据。但任何网络服务都不能保证绝对安全，用户应保留重要照片的独立副本并使用独立强密码。

9. 未成年人

未达到所在地区可独立同意网络服务年龄的用户，应在监护人同意和指导下使用。中国境内未满十四周岁的用户不应自行注册；如发现未经适当同意处理的未成年人信息，请通过私密入口联系删除。

10. 联系与更新

一般功能反馈可使用 GitHub Issues，但不要提交敏感信息。隐私、安全或账号删除请求使用 GitHub 私密报告入口。政策发生实质变化时会更新版本日期；继续使用前可能要求重新确认。
